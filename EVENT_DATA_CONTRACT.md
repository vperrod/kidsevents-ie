# Public event detail contract

Every event shown by Small Days must provide, above any editorial additions:

1. **Description** — sourced from the original listing and clearly displayed.
2. **Original listing** — a direct, labelled link to the page from which the
   event was captured. The source name alone is not sufficient.
3. **Find it on Google Maps** — a link built from verified coordinates where
   available, otherwise venue/address/city/county. If only a broad location is
   known, label it “Search Google Maps”, not “Get directions”.
4. **Last checked / source confidence** — this must be visible when source
   freshness is available.

Do not invent missing venue, price, age or accessibility information. An
unknown value is more trustworthy than a plausible guess.
